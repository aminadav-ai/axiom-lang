# Contributing to Axiom (`axiom-lang`)

Thank you for your interest in **Axiom**!

## Intellectual Property & Pull Request Policy

Axiom is maintained with **100% single-owner intellectual property** so it can be licensed both free of charge for non-commercial use (**BUSL-1.1**) and under clean **Commercial Licenses** for enterprise customers.

- **Bug Reports, Benchmarks, and Feature Ideas (Issues) are warmly welcome!** Reporting an issue or suggesting a design improvement carries no copyright entanglement, and we gladly credit reporters in release notes.
- **External Code Pull Requests:** By default, we do **not** merge unsolicited code Pull Requests unless a signed **Contributor License Agreement (CLA)** is on file granting the Project Owner full, irrevocable rights to relicense and commercialize the contribution. Without a signed CLA, we may close the PR and implement a clean-room solution internally.
